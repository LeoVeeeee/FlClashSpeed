# 2.0.1 代码审查记录

日期：2026-10-08。范围：`src`、接口实现、构建 / 打包脚本、自动化测试及发布文档。第三方 SDK 与 JSON 头文件保持上游原文。

## 发现与处理

| 问题 | 影响 | 2.0.1 处理 |
|---|---|---|
| UI 线程关闭 worker 正在同步读取的 WinHTTP 请求 | 违反句柄并发约束，可能发生竞态或宿主不稳定 | 请求句柄由 worker 的 RAII 对象独占；重连 / 停止通过事件和代次标记通知，在 HTTP 超时后退出旧请求 |
| 重连与旧连接发布状态交错 | 旧速率可能短暂覆盖离线 / 新连接状态 | 在同一状态锁内校验连接代次再发布 |
| 保存的密钥解密失败后继续使用空设置 | 静默连接其他自动发现的控制器 | 保留配置错误，阻止联网，要求用户重新保存有效配置 |
| 多次 INI 写入可能只完成部分字段 | 地址与密钥版本不一致 | 完整 UTF-16 临时文件写入、刷新后原子替换；拒绝换行和过长字段 |
| 持续发送碎片但没有完整 JSON 记录 | 接收超时一直被新字节延后 | 单独监控完整记录的时间，超时断开并重试 |
| JSON 异常信息可能包含输入片段 | 配置密钥或响应内容被带入状态提示 | 使用固定错误消息，避免回显解析输入 |
| README 包含本机路径与交付状态，未完整列出静态运行库许可 | 不适合公开发行或跨设备安装 | 改为通用说明，保留原始版权与许可，发布包包含第三方声明和运行库许可证 |

网络句柄修复依据：[Microsoft 的 WinHTTP 并发约束](https://learn.microsoft.com/en-us/windows/win32/winhttp/concurrency-in-winhttp)和 [WinHttpCloseHandle 文档](https://learn.microsoft.com/en-us/windows/win32/api/winhttp/nf-winhttp-winhttpclosehandle)。

## 验证

`python tools/build.py --arch all` 构建 x64 / x86；`python tests/integration.py` 验证：

- DLL 导出、API 7 虚函数接口、单例、独立显示项和停止流程。
- 单位、小数位及舍入跨位数边界。
- Unicode 路径、DPAPI 往返、加密存储、原子替换和无效保存保留原值。
- 控制器界面覆盖、JSON 分片 / 多条消息、认证失败、超时和零流量。
- 快速连续重连不阻塞宿主，损坏密钥不发起网络请求。
- 不完整的持续数据流超时，错误消息不包含原始响应片段，拒绝远程控制器。

以本次发布包中的 `test-results.txt` 为执行结果记录。CI 对同一命令进行独立复测。

## 已知边界

- 使用官方 API 7 头文件，不改动虚函数顺序；未覆盖所有宿主版本的 ABI 和视觉效果。
- YAML 仅解析两个顶层标量，复杂配置需手动连接。
- 模块在 worker 启动前固定，替换 DLL 需要重启宿主；停止导出主要供诊断宿主使用。
- 手动重连等待旧同步请求在后台超时，可能有数秒延迟。
- 诊断宿主与模拟控制器测试不代替真实 TrafficMonitor 的字体、主题和 DPI 验收。
- 第三方许可条件以随附原文为准。
